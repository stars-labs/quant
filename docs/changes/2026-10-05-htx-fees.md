# HTX account fee verification and settlement guards

Every actual buy and sell now checks the authenticated, symbol-specific effective
HTX taker fee through CCXT fetch_trading_fee. Missing/mismatched/nonfinite rates
prevent a new intent. Both the effective rate and reported basic taker rate must
fit the existing0.30% safety reserve, protecting the envelope if discounts stop
applying between query and fill. The reserve is not a charged fee or PnL assumption.
Actual settled matches remain the only accounting source. Ongoing deduction keeps
an intent pending; nonzero raw HT/point fees pause even when CCXT's normalized fee
would otherwise hide that component. Third-currency deduction is not supported.
